# Contributing

## Current Status

External contributions are not currently accepted.

## Licence

All contributions are subject to the CC BY-NC-ND 4.0 licence.

## Requirements

1. All contributed code must include tests.
2. All contributed code must include evidence of correct operation.
3. All contributed code must follow existing coding conventions.
4. Contributors must certify they have the right to submit the contribution.
5. Contributors must not introduce external dependencies without approval.
