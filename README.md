# ScholaForge

Approval-oriented, human-first, evidence-carrying education operating system architecture providing explainable, equitable benefit distribution across all participants through transparent decision-making and auditable outcomes.

## Purpose

ScholaForge formalises the governance of curriculum decisions, resource allocations, assessment methods and student progression paths within a single evidence-carrying framework designed for Belgian and European Union schools. The architecture ensures that every decision affecting a learner, educator or institution is explainable, equitable, auditable and independently verifiable.

## What the Software Does

The system operates across four interdependent planes:

1. **Human Development Plane.** Addresses learner foundations, cognitive independence, creativity, expertise pathways, health, belonging, agency and lifelong learning trajectories.

2. **Teaching and Learning Plane.** Provides teacher-led learning spaces, tutoring with integrity safeguards (TwinTeach Live), activity design (ActivityForge), multi-format assessment, evidence-linked portfolios, physical movement integration (MotionClass) and accessibility compliance.

3. **Whole-School Services Plane.** Manages identity, attendance, nutrition, facilities, scheduling, administration, family engagement, governance, finance, partnerships and operational continuity.

4. **Trust and Sovereignty Plane.** Enforces rights, privacy, safeguarding, policy gates, four-lens explainability, cryptographic evidence trails (Evidence Spine), model governance, standards-based interoperability (xAPI, LTI, SIS, QTI), offline-first operation through resilient school cells and research transparency.

The architecture introduces the following mechanisms:

| Mechanism | Function |
|-----------|----------|
| MySAGA | Longitudinal, privacy-preserving learner portfolio |
| TwinTeach Live | Real-time co-teaching support under human-authority boundaries |
| MotionClass | Physical movement integration linked to curriculum objectives |
| No-ID Motion Layer | Participation tracking without personal identity linkage |
| Evidence Spine | Cryptographic audit chain binding decisions to rationale and policy |
| INSIGHT Evaluation | Multi-dimensional evaluation of creativity, collaboration, critical thinking and independence |
| Offline Neural Mesh | Full functionality in low-connectivity environments with secure synchronisation |
| Benefit Threshold Gate | Prevents deployment unless measurable benefit to all stakeholders is demonstrated |

## Privacy

The system is designed to enforce data protection by design. The No-ID Motion Layer enables participation tracking without personal identity linkage. MySAGA portfolios are privacy-preserving by design. No personal data is transmitted to external services.
