# CLAIMS

1. A computer-implemented method for explainable adaptive education, comprising:
   receiving real-time learner interaction telemetry at an ingress gateway;
   updating a dynamic Bayesian mastery graph representing prerequisite skills and confidence levels;
   synthesizing a personalized curriculum pathway by selecting learning items that optimize mastery progress under cognitive load constraints;
   generating a transparent pedagogical rationale for each selected learning item, wherein the rationale enumerates prerequisite readiness, diagnostic confidence, and difficulty calibration;
   evaluating a benefit-equity metric across learner cohorts to detect outcome disparities; and
   adjusting curriculum synthesis parameters when the benefit-equity metric indicates a disparity exceeding a safety threshold.

2. The method of claim 1, wherein generating the transparent pedagogical rationale comprises outputting a machine-readable vector bound to the selected learning item and learner telemetry.

3. An adaptive education computing system, comprising:
   a recommendation engine configured to synthesize personalized learning pathways;
   an explainability engine configured to attach transparent pedagogical rationales to learning items; and
   an equity verifier configured to measure learning gain across demographic cohorts and trigger corrective pathway adjustments.
